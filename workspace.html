Everyday Workspace

Save selected browser tabs into named workspaces, search your library, and restore tabs in a new window. Export and import backups whenever you need them.

Privacy policy

Effective October 6, 2026. This policy covers the Everyday Workspace Chrome extension published by Everyday Desk.

Data the extension handles

The extension reads tab URLs, titles and pinned status in your current regular browser window when you open the desk, refresh tabs, or save a workspace. It stores only the tabs you choose to save, workspace names, and creation dates using Chrome's local extension storage. It excludes private/incognito tabs, browser-internal pages, and URLs containing embedded usernames or passwords.

Tab titles, addresses and workspace names may contain personal or sensitive information. Avoid saving sensitive links, and protect your computer and exported backups. The extension does not read page content, passwords, cookies, messages, or your browsing-history database. It does not continuously record browsing activity.

Storage and sharing

Saved workspace data stays in your Chrome profile on your device. The extension uses no developer servers, analytics, advertising, remote code, or cloud synchronization. Everyday Desk does not receive, sell, or share your workspace data. Restoring a workspace opens its saved websites, which then receive ordinary browser requests under their own privacy policies.

Exporting a backup creates a JSON file containing your saved tab URLs, titles and workspace details. Importing reads the file you select and adds its valid workspaces to your local library. You control whether to share exported files.

Permissions

tabs: Read tab URLs, titles and pinned status so you can select and save tabs, and restore their pinned state. storage: Save your workspace library locally between sessions.

Your control

Delete an individual workspace using Delete. Uninstalling the extension removes its Chrome extension storage. Exported files remain wherever you saved them and must be deleted separately. There is no account to create or remote data to request.

Google API Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's workspace features.
